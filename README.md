# Aprenda Go

Aprenda Go é um agregador de links de cursos e tutoriais gratuitos de Go (Golang), com foco na comunidade brasileira. Este projeto utiliza o framework Hugo para gerar um site estático moderno e eficiente.

## 🚀 Começando

### Pré-requisitos

- [Hugo](https://gohugo.io/installation/) (versão extendida recomendada)
- Git

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/biancarosa/aprenda-go.git
cd aprenda-go
```

2. Inicie o servidor de desenvolvimento:
```bash
hugo server
```

O site estará disponível em `http://localhost:1313`

## 📁 Estrutura do Projeto

- `archetypes/`: Templates para novos conteúdos
- `content/`: Conteúdo do site
- `data/`: Dados estruturados
- `public/`: Arquivos gerados (não versionado)
- `resources/`: Recursos do site
- `themes/`: Temas do Hugo
- `hugo.toml`: Configuração principal do Hugo

## 🤝 Contribuindo

Contribuições são bem-vindas! Altere o arquivo `data/menu.toml` para adicionar o novo conteúdo. Inclua o link do conteúdo e o título que será exibido no menu.
